Plug-Ins and Extenions. A plug in is an external application (like how vscode runs extensions in a different process. 
Or like how things like NPAPI/PPAPI worked, 
external dlls running in their own container that could modify contents in the browser) 
that talks to the PaintPower-Engine Application. 
The application can be it's own app installed on the users computer, 
and stored in the "C:\Users\<username>\xPaint\Plugins" folder as a ".plugin" file. The ".plugin" 
type won't just be for the PaintPower-Engine or xPaint apps, but a universal standard for 
application plugins. A plugin is run using an app called a PlugIn Runner. This "Plugin Runner" 
understands the format and knows which application can access this plugin. When loading plugins, 
the PaintPower App looks for plugins in the folder and activates the applications, and starts talking to them. 
The Plugin Runner has different states including: HALTED, WAITING, READY, RUNNING, STOPPED, and UNSUPPORTED.

Extensions run inside of the PaintPower app, but could also use a universal format that either already exists, or make up our own.

Extensions can:

Custom FileEditor (Inside of SpriteEditorView: can create a custom editor for a custom/existing format),
Custom Editor, (Examples of built in editors: ProjectEditor, FolderEditor, WorkspaceEditor, SingleFileEditor)
Custom SpriteEditor (Inside of a ProjectEditor, built in examples: SpriteEditorView, SkinEditor)
Can Modify or make a custom FileExplorer.
Can Modify or make custom File Dialogs, like Open/Save.
Custom themes.
Can create custom language servers for the ScriptEditor that extends FileEditor.
Can depend on Plugins for other things.

Plugins can:

Do everything an extension can, and more.

Because it's running on your computer, in "Plugin Runner" it has Application level access
that could be completely unrelated to the PaintPower-Engine or xPaint like a normal application.

It talks through a special message stream. Can also be done via WebSockets or IOStreaming.

Anyway, they can:

Do everything an extension can, and more.
Modify the VM,
Modify saving,
Modify server settings,
Modify graphics,
Modify runtime,
Custom GUI completely.
